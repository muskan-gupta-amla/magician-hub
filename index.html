Is it safe to merge?

Reads the PR's changes for things that break other code: new or removed procedure parameters, dropped or renamed columns, changed API routes, removed model properties, interface methods, frontend exports, config settings, text keys and deleted files. Then finds where the other Znode repos use them. Also shows whether it is approved, has merge conflicts or failing checks.
